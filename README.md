# Collection Hub v1

A GitHub Pages-ready Progressive Web App for two collections:
- Pokémon Cards
- Coins

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `collection-hub`.
2. Upload all files from this folder to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the Pages address GitHub gives you on your phone.
7. Use **Add to Home Screen** to install it.

## Current v1
- Hub home screen
- Pokémon set browser using Pokémon TCG API v2
- Pokémon card images
- Regular / Reverse Holo / Holo Have tracking
- Have / Need filtering
- Set progress
- Local device storage
- Coin section shell ready for detailed coin data

Important: collection status is currently stored in the browser on each device. Cloud synchronization will be a later phase.
